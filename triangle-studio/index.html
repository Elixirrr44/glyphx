Triangle Studio

Generate copyable combinations with the combining enclosing upward-pointing triangle (U+20E4) on text, emoji and sequences.

The triangle is a Unicode character, not a graphic. U+20E4 COMBINING ENCLOSING UPWARD POINTING TRIANGLE is an enclosing mark (category Me). It has no shape of its own until a font draws it around the character before it — GlyphX attaches it after each whole grapheme cluster, so emoji like 👍🏽 or 👨‍👩‍👧 are never split.

Because rendering is up to the reader’s font, the same text can look like a neat triangle on one device and a detached outline on another. Emoji fonts usually ignore enclosing marks. Check the font previews below before you post.

Compatibility

Renders inconsistently

  • Enclosing mark on an emoji

    Color emoji fonts generally don't position combining marks. The triangle/circle will usually show beside the emoji (or as a hollow shape) rather than around it, and it differs per device.

  • Counts as more characters

    14 code points but 16 UTF-16 units. Many character limits count UTF-16 units, so styled text uses up limits faster.
